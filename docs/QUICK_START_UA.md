# Veil: як почати тест

1. **Android:** установити `dist/Veil-0.1.0-dev.apk` на тестовий телефон. Це development-збірка, не для справжніх секретів.
2. **iPhone:** застосунок спочатку треба зібрати на Mac у Xcode й підписати для свого пристрою. ZIP із кодом — не IPA. Інструкція: `IOS_BUILD.md`.
3. **Сервер:** запустити `dist/veil-relay.pyz` на комп'ютері з Python 3.11+, за HTTPS reverse proxy (`DEPLOYMENT.md`). Публічний сервер автоматично не створюється.
4. На обох телефонах ввести **одну й ту саму HTTPS-адресу** та зареєструвати різні `@handle`. Номер телефону й email не потрібні.
5. Додати контакт за точним handle; спочатку повідомте один одному ці нікнейми іншим каналом.
6. Відкрити відбиток контакту на обох пристроях і порівняти **всі 60 цифр** незалежним каналом. Лише після цього позначати ключ перевіреним.
7. Надіслати тестовий текст. Для отримання повідомлень тримати Veil відкритим: push і фонова доставка ще не реалізовані.

**Важливо:** історія й приватні ключі локальні, але офлайн-повідомлення тимчасово лежать на relay у шифрованому вигляді. Оператор бачить, хто з ким обмінюється повідомленнями, але не повинен мати змоги прочитати текст за коректної клієнтської інтеграції й перевірених ключів. Видалення застосунку або втрата ключів може назавжди втратити акаунт та історію; recovery немає.

Якщо APK ще не зібрано або iOS не перевірено, це прямо вказано в `BUILD_STATUS.md`. Не підміняйте результати тестів фактом наявності файлів.
